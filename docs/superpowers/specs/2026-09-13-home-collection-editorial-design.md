# Homepage collection: integrated index and photographic rhythm

## Scope

Refine the published HomeStudio chapter index and six-category installation gallery. The user delegates visual implementation without approval rounds. Preserve the existing hero, its mobile transparency, floating contacts, all six category names/order/routes, source imagery, and concise copy. No browser preview, image generation, commit or push.

## Source assessment

- Reading order: the 15px chapter links in a separate 88px charcoal bar are visually subordinate to both adjacent photographic sections, without belonging to either.
- Grouping: the product heading is centered, while disconnected captions and arrows spread beneath six equally sized photographs.
- Rhythm: equal three-column widths and identical row spacing give every image the same emphasis. The detailed room backdrop competes with the installed-device images.
- Density and adaptation: only names are needed here; model facts stay on detail pages. Keep DOM order and all six links. At intermediate widths use two equal columns; phones retain the complete-image single-column gallery and a wrapping chapter index.
- Extremes: Standard Receptacles must wrap naturally; image height remains driven by the original 3:2 ratio. Contact controls, focus indicators, reduced-motion behavior and 44px touch targets remain available.

## Direction

Treat the area as a product editorial spread, not a second catalog. Move the six existing chapter links into the collection backdrop above its heading. Enlarge link text, emphasize the collection entrance and outline the existing inquiry action. Keep the index transparent and bounded to the same content width; no inter-section gradient or separate solid navigation strip.

Use a 12-track desktop grid with three entries per row: 5/4/3 tracks, then 3/5/4. GFCI, the signature product, and Smart Switches lead their respective rows. Top-row images share a lower caption line; the second row opens from a common upper edge. All photographs retain their original complete 3:2 frames, with a 12px corner and one soft shadow. Names remain below images; a decorative 44px outlined arrow strengthens the existing whole-card link.

The backdrop remains the same room image, rendered at .55 opacity over charcoal with the existing neutral overlay. It supports rather than competes with the products. The existing image-entry animation remains; a fine-pointer hover gently brightens the image and moves the arrow, with keyboard and reduced-motion fallbacks.
