# Fahint 首页毛玻璃导航设计说明

日期：2026-08-25  
状态：已确认设计方向，待实施

## 目标

把首页现有的全宽透明/白色导航改为更紧凑、更有品牌感的悬浮毛玻璃导航。导航需要覆盖在首页深色首屏之上，同时在滚动后和内页保持清晰、稳定、易读。

## 已发现的问题

- 当前 Logo 是由字母方块和文字拼出的临时标识，不是旧站保存的 Fahint 正式 Logo。
- 在 2560 × 1440 全屏尺寸下，Logo 右侧到菜单左侧的实际距离约为 331px，视觉关系松散。
- 当前菜单通过 `margin-left: auto` 撑开，Logo、菜单和询盘按钮不像一个完整的导航组件。
- 滚动后导航变成整条白色横栏，与首页深色海报之间缺少精致的悬浮层次。

## 采用方向

采用“浅色悬浮毛玻璃胶囊”方案。

### 外框

- 导航居中悬浮，桌面端最大宽度约 1480px。
- 距离窗口顶部约 18px，左右至少保留 32px 安全距离。
- 高度约 76–78px，圆角约 24px。
- 背景使用浅灰白半透明玻璃，而不是纯白或完全透明。
- 玻璃参数以约 20–22px 模糊、适度饱和和轻微透明度为基准。
- 使用 1px 半透明亮边和柔和深蓝阴影，避免厚重发光或过强投影。

### Logo

- 使用旧站真实品牌 Logo：深蓝透明版本 `logo2.png`。
- 项目内保存为语义明确的品牌资源文件，不继续引用旧站目录。
- 桌面端显示宽度约 160–170px，保持原始比例，不添加额外文字或方形 F 图标。
- 浅色玻璃下始终使用深蓝 Logo，保证辨识度。

### 桌面布局

- 不再使用菜单自动占满剩余空间的布局。
- 导航内部按 `Logo / 主菜单 / 询盘按钮` 三组排列并整体居中。
- 目标间距：Logo 到菜单约 64–72px，菜单到询盘按钮约 36–40px。
- 主菜单内部间距约 28–30px，保持现在的栏目顺序。
- 询盘按钮保留品牌蓝，但尺寸稍微收敛，与毛玻璃外框形成主次关系。
- 当前页面下划线保留，长度仅跟随文字，不贯穿大面积空间。

### 首页顶部状态

- 首屏顶部直接显示浅色毛玻璃导航，让真实 Logo 和黑/深蓝文字保持清晰。
- 背后的首屏图片仍可透出少量色彩和明暗，但不能影响文字阅读。

### 滚动与内页状态

- 滚动后仍保持悬浮胶囊结构，不切换成全宽白条。
- 仅适度提高背景不透明度和阴影强度，尺寸和内容位置不跳动。
- 内页使用相同组件和更高一点的不透明度，保证网站整体一致。

### 产品下拉菜单

- 保留现有产品下拉功能。
- 下拉面板从毛玻璃导航下方展开，顶部距离与外框圆角协调。
- 下拉面板仍以高可读性的浅色实体卡片为主，不强行使用透明玻璃。

### 平板与手机

- 900px 以下继续切换为 Logo、菜单按钮和移动菜单。
- 移动端导航同样采用圆角毛玻璃外框，但缩短高度和顶部间距。
- Logo 保持完整，不裁切为单独字母图标。
- 移动菜单展开后保持足够对比度、触控尺寸和可滚动性。

## 动效

- 导航初次出现使用轻微下移到位和透明度渐入，时长约 320–420ms。
- 滚动状态变化使用 180–240ms 的背景、边框和阴影过渡。
- 不使用持续漂浮、强缩放或明显弹跳。
- 遵循 `prefers-reduced-motion`，关闭非必要动画。

## 验收标准

- 2560 × 1440 全屏下，Logo、菜单和询盘按钮形成紧凑的一组，Logo 到菜单不再出现超过 300px 的空档。
- 正式 Logo 清晰、比例正确，没有临时 F 图标和重复品牌文字。
- 导航在首屏、滚动状态、内页和移动端均可读且没有布局跳动。
- 产品下拉菜单和移动菜单功能保持正常。
- 不遮挡首屏标题，不与浏览器边缘贴得过近。
- 桌面端、常规笔记本宽度和手机端均无横向溢出。
