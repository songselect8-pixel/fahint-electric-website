# Fahint 常驻毛玻璃导航与移动端图片适配设计说明

日期：2026-08-29  
状态：设计方向已确认，待实施

## 背景与目标

当前导航采用四周留白、圆角较大的悬浮卡片结构。用户希望恢复为页面顶部常驻的完整导航栏，同时保留克制的毛玻璃质感。网站在手机端还存在横向场景图裁切过度、产品主体没有完整进入画面的问题。

本次设计同时解决以下两点：

- 导航不再悬浮于页面之上，改为正常占据文档顶部空间并在滚动时吸顶。
- 手机端优先保证产品主体可见，通过媒体类型、画面比例和焦点位置适配现有素材；只在现有原图无法满足时补充少量手机专用图片。

## 已确认方案

采用“全宽吸顶毛玻璃导航 + 语义化移动端图片适配”方案。

不采用全屏覆盖式固定导航，因为它会遮挡首屏内容；不为所有图片机械生成手机版本，因为这会增加大量重复文件，也可能再次出现产品结构和插头位置错误。

## 导航设计

### 定位与页面关系

- 导航使用正常文档流中的吸顶定位：初始状态占据页面空间，滚动后保持在窗口顶部。
- 导航的毛玻璃背景覆盖整个视口宽度，不保留左右悬浮边距。
- 页面首屏、面包屑和内容区不再为旧的覆盖式导航重复预留顶部高度。
- 导航吸顶后不改变高度和内容位置，避免滚动时产生跳动。

### 视觉语言

- 背景使用浅灰白半透明玻璃，配合适度模糊和饱和度提升。
- 底部使用一条低对比度边框和轻微阴影，用于区分页面内容。
- 去除外层大圆角、胶囊形轮廓和四周大面积投影。
- Logo、主菜单和询盘按钮沿用现有品牌层级，导航内部保留居中的最大内容宽度。
- 滚动后只轻微提高背景不透明度和阴影，不改变布局。

### 桌面端布局

- 导航高度约 76–80px。
- 内部采用 Logo、主菜单、询盘按钮三组布局，整体保持紧凑。
- 产品下拉菜单从导航底边展开，保留实体浅色面板和清晰边界。
- 当前页状态、键盘焦点和下拉交互保持现有功能。

### 手机端布局

- 手机端导航高度约 62–66px，同样全宽吸顶。
- Logo 与菜单按钮保留足够触控区域，不使用悬浮小胶囊。
- 展开菜单从导航下沿衔接，使用整宽毛玻璃/高不透明浅色面板；菜单内容可独立滚动。
- 页面滚动锁定、关闭按钮、Esc 关闭和焦点行为保持可访问性。

## 移动端图片适配

### 处理原则

每张图片按用途分为三类，不再使用一套统一的 `object-fit: cover` 规则：

1. 产品证据图、产品结构图、包装图和尺寸图：必须完整显示主体，优先使用 `contain`，并为留白提供与版块一致的背景。
2. 产品应用场景图：允许裁切环境，但产品和插头/插座连接区域必须完整可见；使用适合手机的画框比例和逐图焦点。
3. 纯氛围背景图：继续使用 `cover`，但调整手机端画面高度与焦点，避免主体被标题或边缘遮挡。

### 首页

- 审核首屏、产品系列、应用场景、制造能力和底部联系区域的所有图片容器。
- 移除在窄屏中强制使用过高固定高度的规则，改用与素材相符的 `aspect-ratio` 或内容高度。
- 产品卡中的产品必须完整进入画面；场景卡允许环境裁切，但关键产品不得出框。
- 不以放大图片填满卡片为唯一目标，宁可保留可控留白也不截掉产品。

### 产品详情页

- 产品图库、颜色选择图、包装图、证书和技术图继续以完整展示为主。
- 应用场景图按型号设置移动端焦点；插座、插头与连接区域必须处于安全区。
- 同类产品页使用统一结构，但每个型号允许拥有独立的移动端焦点位置。
- 不修改产品参数和型号数据。

### 新图片生成边界

- 第一轮只调整布局、画框比例、`object-fit` 和 `object-position`，不生成新图片。
- 只有在原始图片主体靠近边缘、任何合理裁切都无法完整展示时，才制作手机专用版本。
- 手机专用版本按实际缺失项逐张补充，不批量生成；沿用现有资源目录与命名规则，避免重复文件。

## 响应式与可访问性

- 导航和菜单在 320px 至大屏宽度均不得产生横向溢出。
- 图片需要保留明确的 `alt` 文本；装饰图片按现有规则处理。
- 交互元素的手机端最小触控尺寸保持约 44px。
- 毛玻璃背景下文字和图标对比度必须稳定，浏览器不支持 `backdrop-filter` 时提供高不透明度背景回退。
- 尊重 `prefers-reduced-motion`，不新增不必要动画。

## 验收标准

- 桌面和手机导航均为全宽、正常占位、滚动吸顶的毛玻璃导航，不再显示四周悬浮圆角卡片。
- 首页和所有产品详情页首屏不被导航覆盖，也没有旧补偿空间导致的大段空白。
- 手机端所有重要图片能看到产品主体；产品图不因 `cover` 被切掉，场景图的插座和连接区域不出框。
- 产品下拉、移动菜单、询盘入口和页面链接功能保持正常。
- 不批量增加新图片；只有确认 CSS 无法解决的素材才新增移动端版本。
- 桌面端、平板端和手机端均无横向滚动、布局跳动或图片容器异常拉伸。
