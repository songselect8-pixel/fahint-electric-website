# Fahint 首页克制型动效优化设计

日期：2026-08-25

## 1. 目标

在不改变首页内容结构、版块顺序、文案、图片、路由和独立悬浮按钮的前提下，重建统一、克制、偏高端工业品牌的动效语言。

本轮重点解决：

- 全页重复使用“淡入＋上移”，滚动过程模板感明显。
- 版块和内部卡片同时执行 Reveal，造成双重等待。
- 首屏与图片悬停动画偏慢，操作反馈不够利落。
- `reveal--from-left` / `reveal--from-right` 的命名与实际运动不一致。
- 动画数量多但缺少明确的品牌级焦点。

## 2. 动效主张

采用“一个主动画，少量辅助反馈”的克制型工业电影感：

- 首屏是唯一完整编排的焦点动画。
- 页面滚动主要依靠稳定排版、深浅背景和图片构图建立章节感。
- 只在图片揭示、流程顺序和用户操作需要反馈时使用动画。
- 删除不能解释层级、关系或状态的装饰性动画。

## 3. 首屏动画

- 首屏背景从约 `scale(1.02)` 恢复至 `scale(1)`，时长约 800ms。
- 背景同时进行一次轻微明暗稳定，不加入循环视差或持续漂浮。
- 眉题、标题、说明与按钮作为一个短序列完成入场，总时长不超过 760ms。
- 元素错峰控制在 40–70ms，不让用户等待标题逐行播放。
- 导航栏保持独立，不与首屏内容一起淡入。

## 4. 滚动与版块过渡

- 移除首页主要 `section` 根节点的通用位移 Reveal。
- 版块背景、标题和正文默认直接可见，不因脚本或滚动位置隐藏。
- 品牌、应用、定制和工厂等主要图片可使用一次轻微遮罩揭示：从 98% 可见到完全展开，时长 480–620ms。
- 遮罩只作用于图片容器，不移动整块文字和布局。
- 版块之间的自然衔接继续由背景色、1px 分隔线、上下留白及图片边界承担。

## 5. 卡片、数据与流程

- 六个产品入口按行出现，不对每张卡片执行长时间单独入场。
- 同一行最多使用 50–70ms 错峰，总延迟不超过 140ms。
- 应用场景卡片使用相同规则，避免一屏内连续等待四次。
- OEM/ODM 四步流程与工厂能力数据允许短暂错峰，帮助表达阅读顺序；单项动画 320–420ms。
- 证书、博客、FAQ 和表单不执行整块滚动位移，只保留必要的状态反馈。

## 6. 悬停与操作反馈

- 产品、应用和博客图片悬停缩放控制在 `1.012–1.018`，时长 260–320ms。
- 箭头水平移动 4px，时长 160–200ms。
- 按钮背景、边框和文字颜色切换控制在 160–220ms。
- 卡片不整体上浮，不使用大阴影跳变、弹跳或发光。
- FAQ 展开保留高度和图标反馈，但时长缩短至 240–300ms。
- 导航与悬浮联系按钮继续保留各自现有交互，不合并。

## 7. 性能与无障碍

- 不新增动画依赖，继续使用 CSS 与现有 React 结构。
- 优先使用 `transform`、`opacity` 和受控的 `clip-path`，不动画高度、外边距或定位属性。
- 移除长期存在的 `will-change`，只在确有必要的局部元素使用。
- `prefers-reduced-motion: reduce` 下关闭位移、缩放和遮罩动画，同时保留颜色、焦点和展开状态反馈。
- 内容默认可见；IntersectionObserver 失败时不影响阅读。

## 8. 响应式规则

- 桌面验收以 2560×1440 全屏视口为准，同时检查 1440px 与 1024px。
- 手机端不执行图片遮罩和卡片错峰，只保留 150–200ms 的按钮与状态反馈。
- 动画不能改变版块高度、造成布局跳动、横向滚动或遮挡右侧悬浮按钮。

## 9. 实施范围

预计修改：

- `src/components/Reveal.jsx`
- `src/components/home/EditorialHomepageFront.jsx`
- 必要时调整下半部分首页组件的 Reveal 使用方式
- `src/styles.css`
- `src/pages/Home.test.jsx`

不修改：

- 首页内容结构和版块顺序
- 产品资料、图片和链接
- 导航栏视觉方案
- 博客、FAQ、完整询盘表单
- 独立悬浮联系按钮

## 10. 验收标准

- 首屏动画在约 800ms 内完成，进入网站后可立即操作。
- 首页不再出现 12 个版块重复上移、29 个元素依次等待的情况。
- 滚动时内容稳定，图片揭示自然，版块衔接主要依靠设计而非动画。
- 产品卡片、按钮、FAQ 与箭头反馈统一且利落。
- 2560px 桌面和 390px 手机无布局跳动、溢出和遮挡。
- 低动态模式有效，测试、构建与浏览器控制台检查通过。
